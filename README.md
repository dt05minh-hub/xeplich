# Adaptive Personal Planner 🚀

Ứng dụng Lập lịch Cá nhân Thích ứng Thông minh kết hợp Google Gemini AI.

## 🌟 Tính năng nổi bật

- **AI Smart Scheduler**: Tự động phân bổ lịch làm việc, học tập, thi cử và việc cá nhân tối ưu theo năng lượng và ràng buộc thời gian.
- **Adaptive Rule Generator**: Phân tích lịch sử hành vi và phản hồi của người dùng để rút ra quy luật công việc phù hợp cá nhân.
- **Active Time Tracker**: Theo dõi thời gian thực hiện công việc thực tế, so sánh sai số dự kiến.
- **Weekly Insights & Co-Pilot Chat**: Báo cáo năng suất tuần và trợ lý trò chuyện AI đồng hành.

---

## 🛠️ Hướng dẫn cài đặt & Chạy ứng dụng

1. **Clone dự án:**
   ```bash
   git clone https://github.com/dt05minh-hub/adaptive-personal-planner.git
   cd adaptive-personal-planner
   ```

2. **Cài đặt thư viện:**
   ```bash
   npm install
   ```

3. **Cấu hình Biến môi trường (`.env`):**
   Tạo tệp `.env` tại thư mục gốc và cấu hình:
   ```env
   GEMINI_API_KEY="your_gemini_api_key_here"
   PORT=3000
   ```

4. **Khởi chạy Server:**
   ```bash
   npm run dev
   ```
   Ứng dụng sẽ chạy tại: `http://localhost:3000`
